# Domain Docs

Before exploring, read the root `CONTEXT.md` if present and relevant ADRs in `docs/adr/`.
If those files do not exist, proceed without flagging their absence.

This is a single-context repository:

- `CONTEXT.md` contains domain vocabulary only.
- `docs/adr/` contains durable architectural decisions.
- Use the glossary's terms in plans, issues, tests, and refactor proposals.
- Surface conflicts with existing ADRs instead of silently overriding them.
